# Правила интерфейса YAP

- Подчёркивание текста разрешено только для ссылок. При наведении не добавляй подчёркивание. Для обратной связи используй цвет или фон. Текст кнопок и других элементов управления должен оставаться без подчёркивания во всех состояниях, включая наведение, фокус и нажатие.
- При закрытии модальных окон и переходе между страницами сохраняй текст элементов, которые остаются на экране. Их подписи и содержимое не должны пропадать, мигать или временно подменяться. Текст меняется, когда изменились данные или пользователь выполнил действие, которое меняет этот текст.
- Для длительных операций добавляй анимированный визуальный индикатор загрузки. Если прогресс измерим, показывай шкалу прогресса. Если длительность неизвестна, показывай спиннер или анимированный скелетон. Сохраняй подпись кнопки во время операции. Текстовый статус может дополнять индикатор, но не заменяет его.
